INSTALLATION
1. Upload replacement index.html, style.css, and app.js.
2. Keep your existing login.html, login.js, Supabase configuration, and database.
3. Log out and log back in.
4. Press Ctrl+F5.

NOTES
- Reports are available only to administrators.
- PDF reports use jsPDF and AutoTable from CDN.
- Excel reports use SheetJS from CDN.
- No database migration is required for the reporting update.
